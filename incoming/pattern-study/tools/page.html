패턴 연구

새 패턴 개예요(). 모두 패널을 세운 64×128 로 그리고, Pattern Lab 의 엔진으로 돌아가요. 노브는 Lab 의 기본 노브 값 0, 2, 0, 0.06 을 패턴의 범위 안으로 당긴 자리에서 시작해요. 마음에 드는 것은 「코드 복사」로 가져가 Lab 의 CODE 칸에 붙여 넣으면 돼요. 붙여 넣으면 노브는 그때 Lab 에 있던 값을 새 범위로 당긴 자리에 서니, 같은 화면을 보려면 카드의 슬라이더 값대로 Knobs 칸을 맞춰요.

점 하나가 패턴 하나예요. 누르면 그 패턴으로 가요. 흰 테두리 점이 2판이에요. 점선 칸은 아직 아무 패턴도 없는 자리예요. 자리는 카드의 처음 노브 값에서 8초 동안 돌린 화면을 재서 정했고, 거의 같은 자리에 겹친 점은 조금 떼어 놓았어요.
