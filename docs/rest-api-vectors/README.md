# REST vectors

Each file here is one sentence of [rest-api.md](../rest-api.md) and the requests that show a panel doing it, written as [contract-vectors.md](../contract-vectors.md) sets out. `npm run check:rest-vectors` in `web/` replays every one against a fresh [virtual panel](../../tools/virtual-panel/README.md) and prints what the vector expects beside what the panel did. CI runs it on every pull request with the other drift checks. When the spec rewords a sentence a vector quotes, that vector fails until someone brings it along.

A file's name starts with the part of the spec it reads. `state-` is `GET /api/status`, `POST /api/params` and `POST /api/sleep`. `device-` is the rest of device state (`/api/display`, `/api/knobs`, `DELETE /api/crash`) and what every route shares, such as the plain-text 404 and `no-store`. `patterns-` is the pattern list, select and the module files. `absent-` is a route a build leaves out because its feature is not in it. The vectors for a route only a feature serves start with that feature's directory in `firmware/patternflow/features/`, as `mqtt-` does for `/api/mqtt`, and name the feature in `features`.

Some of the spec has no vectors. The virtual panel has no radio and no flash volume, so Wi-Fi and the hotspot, firmware updates, and installing, deleting or formatting modules are not replayed. It has no microphone and does not run the clock or shows, so `/api/audio-in`, `/api/clock` and `/api/shows` are not replayed either. The console's pages are for a person and have no vectors.

Two firmware rules are not in rest-api.md, and the virtual panel keeps both. A hand does not take back a channel that `POST /api/params` wrote less than 250 ms before (`ABSOLUTE_RELEASE_GRACE_MS` in `core_bus.h`). A sleeping panel ignores its knobs and buttons for the first 800 ms (`WAKE_GUARD_MS` in `core_sleep.h`). A vector that puts a hand on the panel after either one waits it out: `state-params-hand.json` holds the channel a second before the turn, and `state-sleep-wake.json` lets the panel sleep a second before waking it.
